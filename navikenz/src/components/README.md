# Components

This folder contains reusable React components shared across pages.

## Files

- `AuthShell.jsx` provides the authentication page layout.
- `Button.jsx` provides a reusable button primitive.
- `ChatLimitModel.jsx` shows the guest limit modal and sends users to signup.

## Guidelines

- Keep components reusable and mostly presentation-focused.
- Put screen-level data flow in `src/pages`.
- Put HTTP calls in `src/services`.
