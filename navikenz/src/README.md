# Source

This folder contains the React source code for the Navikenz frontend.

## Files

- `main.jsx` mounts the application.
- `App.jsx` coordinates Auth0 state, guest mode, signup/login, and dashboard rendering.
- `auth0Config.js` stores frontend Auth0 configuration.
- `index.css` contains global styles and Tailwind imports.

## Folders

- `assets/` contains bundled static assets.
- `components/` contains reusable UI components.
- `pages/` contains screen-level React components.
- `services/` contains browser-side API clients.
